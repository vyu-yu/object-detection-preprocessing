# Sample Data

This directory contains two sample images and their DOTA-style oriented bounding box labels for demonstration and tests.

- `P2591.png` / `P2591.txt`
- `P2629.png` / `P2629.txt`

The sample imagery comes from the DOTA aerial-image object-detection dataset. The imagery and annotations remain subject to the original dataset and image-source terms; they are not covered by this repository's MIT source-code license.

Dataset reference:

> Xia, G. S., Bai, X., Ding, J., Zhu, Z., Belongie, S., Luo, J., Datcu, M., Pelillo, M., & Zhang, L. (2018). DOTA: A Large-scale Dataset for Object Detection in Aerial Images. CVPR.
